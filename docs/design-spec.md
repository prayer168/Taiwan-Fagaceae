# 教材藍圖

## 基本資料

- 中文教材名稱：臺灣殼斗科探索
- 英文專案名稱：Taiwan Fagaceae
- GitHub repository 候選名稱：`Taiwan-Fagaceae`（來源：專案資料夾名稱）
- 適用年級：國小五年級
- 科目：自然科學
- 學習時間：40 分鐘
- 模式：引導模式
- 視覺風格：清爽、自然、教學寫實

## 初步學習方向

- 從可觀察的葉、果實與殼斗特徵認識植物。
- 練習比較、分類與以證據說明判斷。
- 了解殼斗科植物與臺灣森林生態及日常生活的關係。

正式學習目標、先備知識、核心概念與課綱對應，須在內容研究與教師確認後定稿。

## 頁籤架構

1. 學習任務：教材目標、時間與學習引導。
2. 特徵探索：以圖解觀察葉、果實、殼斗等特徵。
3. 互動觀察：規劃點擊觀察與拖曳分類兩種以上互動。
4. 生命故事：規劃種子、萌發、成長與森林關係的階段動畫。
5. 生活應用：規劃六則有獨立視覺證據的生活或生態情境。
6. 闖關挑戰：規劃十題理解、應用、推理與圖像判讀題。
7. 自主學習：規劃八筆經查核的政府、研究或博物館資源。

## 預計檔案

採用根目錄 HTML、分離的 CSS 與 JavaScript、JSON 教材資料，以及 `docs/` 中的教案、設計與測試文件。詳細結構見 `README.md`。
