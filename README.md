# 臺灣殼斗科探索

適合國小五年級自然科學課程的互動教材專案。目前為 v0.1.0 初始化骨架，後續將加入經查證的教材內容、SVG 圖解、互動觀察、生活應用、闖關評量與自主學習資源。

## 學習方向

- 觀察殼斗科植物的外形特徵。
- 運用比較與分類整理觀察證據。
- 連結臺灣森林生態與生活經驗。

正式學習目標與課綱對應仍待內容研究及教師確認。

## 教材頁籤

學習任務、特徵探索、互動觀察、生命故事、生活應用、闖關挑戰、自主學習。

## 本機啟動

```bash
npm install
npm run dev
```

正式建置：

```bash
npm run build
```

## 專案結構

- `index.html`：教材頁面殼層
- `css/`：版面、動畫與響應式樣式
- `js/`：導覽、互動、測驗與進度功能
- `data/`：教材內容、題庫、資源與課綱資料
- `assets/`：圖片、圖示、影音素材
- `docs/`：教案、設計規格、來源與測試報告

## 使用技術

HTML5、CSS3、原生 JavaScript、JSON、Vite。
